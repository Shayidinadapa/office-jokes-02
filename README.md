Entry for the [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc) bounty on make.fun: a program that writes one single-line joke about office life to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`main.ts` runs on Node 22 and writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating it first: 1–199 characters, a single line, non-blank, no control characters.
